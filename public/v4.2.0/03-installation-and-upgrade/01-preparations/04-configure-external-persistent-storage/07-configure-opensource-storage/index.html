Configure Open Source Storage Systems

Time updated：2025-10-30 06:24:17
Page Catalog

KubeSphere supports numerous third-party open source storage systems, including but not limited to:

  • Ceph CSI

  • GlusterFS

  • OpenEBS

  • Longhorn

KubeSphere does not provide installation packages for third-party open source storage systems. Please download and install them from the official websites of the storage systems.
