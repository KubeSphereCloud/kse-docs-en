CAS Authentication

Time updated：2025-09-12 01:41:06
Page Catalog
  • Steps
  • CAS Basic Configuration
  • CAS Complete Configuration
  • CAS Parameter Description

KubeSphere supports external authentication through Central Authentication Service (CAS), allowing users to log in to the KubeSphere Enterprise web console using their CAS username and password.

Platform administrators can configure CAS authentication through Secrets.

Steps

  1. Log in to the KubeSphere Enterprise web console with a user having the platform-admin role.

  2. Click Cluster Management and enter the host cluster.

  3. Click Configuration > Secrets in the left navigation pane.

  4. Click Create on the page.

  5. In the Create Secret dialog, click the Edit YAML toggle in the upper right corner to create the Secret using YAML.

  6. Modify the YAML file according to the following example and parameter descriptions. After configuration, click Create.

  7. Log out of the KubeSphere Enterprise web console. On the login page, click Log in via CAS, and enter your CAS username and password to log in.

Note

In a multi-cluster environment, configuration is only required in the host cluster.

CAS Basic Configuration

apiVersion: v1
kind: Secret
metadata:
  namespace: kubesphere-system  # Do not modify
  name: identity-provider-cas  # Ensure this Secret name is unique within the Kubernetes cluster
  labels:
    config.kubesphere.io/type: identityprovider # Do not modify
    config.kubesphere.io/identityprovider: cas # Must match the `name` field in configuration.yaml
type: config.kubesphere.io/identityprovider # Do not modify

stringData:
  configuration.yaml: |
    name: cas
    type: CASIdentityProvider
    mappingMethod: auto
    hidden: false
    disabled: false
    displayName: "cas"
    provider:
      # Required fields
      redirectURL: "https://your-app.com/cas/callback"
      casServerURL: "https://cas.example.com/cas"

CAS Complete Configuration

The following only shows the configuration of the provider section under stringData:configuration.yaml. Other parts should remain the same as the corresponding parts in CAS Basic Configuration.

    provider:
      # Required fields
      redirectURL: "https://your-app.com/cas/callback"
      casServerURL: "https://cas.example.com/cas"

      # Optional fields
      insecureSkipVerify: false
      displayNameAttribute: "displayName"

CAS Parameter Description

This is the parameter description for the provider section under stringData:configuration.yaml. For parameter descriptions of other parts in the Secret, please refer to Configure External Authentication.

Parameter Type Required Default Description

redirectURL

string

Yes

-

CAS client callback URL

casServerURL

string

Yes

-

CAS server root URL

insecureSkipVerify

bool

No

false

Whether to skip TLS certificate verification

displayNameAttribute

string

No

-

Attribute name for user display name
