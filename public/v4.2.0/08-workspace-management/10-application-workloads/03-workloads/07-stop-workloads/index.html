Stop Workloads

Time updated：2025-12-22 09:26:17
Page Catalog
  • Prerequisites
  • Steps

This section describes how to stop a workload.

Warning

This operation will scale the number of running pod replicas in the workload to 0, which will interrupt the business running in the workload. Please perform this operation with caution.

Prerequisites

You need to join a project and have the Application Workload Management permission in the project. For more information, see Project Members and Project Roles.

Steps

  1. Log in to the KubeSphere web console with a user who has Application Workload Management permissions and enter your workspace.

  2. Click Application Workloads > Workloads in the left navigation pane.

  3. On the Workloads page, click Deployments, StatefulSets, or DaemonSets to open the workload list.

  4. Select a project from the drop-down list in the upper left corner of the page.

  5. Select the checkbox on the left of the workload you want to operate, then click Stop above the workload list.

  6. In the Stop Workload dialog box, enter the name of the workload, then click OK.

    Note

    Use commas (,) and spaces to separate multiple names.
